# My Dear Kebab — сайт

Многостраничный сайт кафе My Dear Kebab (Минск, Комсомольская ул., 3): меню с поиском и фото, атмосфера, контакты. Дизайн в духе самого заведения: тёмная плитка, тёплый янтарный свет, деревянная решётка с геометрическим узором. Выбор трёх случайных блюд на главной. Чистые HTML, CSS и JS без сборки.

**Страницы:** `index.html`, `menu.html`, `kitchen.html` (кухня), `atmosphere.html`, `contacts.html`.

## Что менять
Всё в `js/data.js`: `SITE` (адрес, телефон, соцсети, время работы) и `MENU` (категории и блюда). Позиция: `[id, название, описание, [[вариант, цена, вес]]]`.

## Фото блюд
Положи `.jpg` в `images/menu/` и назови по id блюда из `data.js` (например `doner.jpg`). Подробности в `images/menu/README.txt`. Без фото рисуется узор.

## Публикация на GitHub Pages
Залей содержимое папки в корень репозитория (не `.zip`), затем **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
